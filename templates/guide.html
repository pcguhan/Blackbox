Local account

Challenges and flags

Open Challenges to search by title or description and filter by category or solve status. Read the brief for provided files, connections, and prerequisites.

The default flag format is CYS{...}.{% if flag_prefix != 'CYS' %} This event uses {{ flag_prefix }}{...} as its configured format.{% endif %} If the challenge specifies an override, follow its format. Submit the complete flag, including any required braces, in the Flag field.

Container instances

  1. Select Start Container Instance on a challenge that provides one.
  2. When the instance is running, use the connection details shown in its panel. The countdown shows how much time remains.
  3. Stop the instance when you finish. If it expires before you solve the challenge, start a new instance and use its displayed connection details.

Scoring and hints

A team earns points once per challenge. When a teammate solves it, the challenge is marked solved for everyone on the team. Static challenges keep their point value. Dynamic challenge values can fall as more teams solve them.

A paid hint deducts its displayed cost from the team's score, or from your score if you play without a team. The hint is then available to the whole team when playing together.

The leaderboard ranks teams by their scores when team play is enabled.{% if current_user.is_authenticated and (scoreboard_visible or current_user.is_admin) %} View the leaderboard.{% endif %}
